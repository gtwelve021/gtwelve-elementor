# gtwelve-elementor

## G12 Mega Header

Version 1.0.117 includes **G12 Mega Header** in Elementor's GTwelve category, based on the supplied header HTML. Add it to a full-width header container with zero padding. Use one global header per page.

The content sections expose the supplied labels, URLs, images, and image alt text, with Elementor dynamic tags enabled. The original menu hierarchy is preserved; these controls edit its existing content rather than adding or removing menu groups. Style controls cover accent, text, border, and top-bar colors. Header Settings includes sticky positioning and top-bar visibility.

The widget includes its own fonts, images, CSS, and JavaScript. Desktop mega menus, nested tabs, mobile accordions, Escape-to-close, focus trapping, and the compact scroll state follow the supplied design. The existing G12 Site Header remains available.
